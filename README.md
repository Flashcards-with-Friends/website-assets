# Flashcards with Friends — Assets

This repository is the official storage for assets used by https://flashcardswithfriends.com.

It contains images, icons, fonts, and other static media that power the website and related projects. This repository should be treated as the single source of truth for production assets.

## Contents
- Images (logos, icons, illustrations)
- Fonts
- SVGs and other vector assets
- Favicons and social preview images

## Usage
Fetch or reference assets directly from this repository in builds, deployments, or other repositories. When linking from the website or other projects, prefer using the production-hosted asset URLs/paths provided by your deployment pipeline.

Best practices:
- Reference assets by exact filename and path to avoid cache misses.
- Prefer optimized and compressed formats for raster images (e.g., WebP, compressed PNG/JPEG) and cleaned SVGs for vectors.

## Contributing
See CONTRIBUTING.md for contribution guidelines. In general:
- Add new or updated assets in a clear, versioned manner.
- Include a short description of the change in the commit message.
- Avoid committing large editor or source files; prefer optimized raster/vector files.
